一、策略从哪来：三个版本的差异

通用解题策略不是某个人的发明，而是百年教学研究的沉淀。弄清版本差异，你才知道每一步为什么存在。

版本步数内容差异关键
早期四步版
Polya, 1945		4 明确问题 → 拟定计划 → 实施 → 回顾 开山之作，但从“弄清问题”直接跳到“拟定计划”，中间缺了一块
六步版
McMaster 体系		6 增强动机 → 明确问题 → 探索思考 → 拟定计划 → 实施 → 回顾 补上了“探索”，并额外强调动机
本站五步5 明确问题 → 探索思考 → 拟定计划 → 实施执行 → 回顾总结 保留“探索”；把动机与态度贯穿全程，不单列为一步
本章最重要的一个判断 “探索思考”是四步版与后续版本最大的差异点，也是新手最容易跳过、代价最高的一步。 跳过它，你会在错误的路上高效地狂奔。

二、本章目标：应知／应会／理解／迁移

应知（知道“是什么”）

  • 说出五步的名称与顺序
  • 说出每一步的核心任务与产出物
  • 说出三个版本的差异及原因
  • 说出“探索思考”为何不可跳过

应会（标准情境“做得出”）

给一道陌生题，你能：

  1. 按五步走完，每步都有书面产出
  2. 探索步列出 ≥3 条候选路径
  3. 回顾步给出验证、替代解、推广变体
  4. 卡住时能定位在第几步并回退

深度理解（知道“为什么”）

  • 解释“最佳解取决于资源与准则”，会用逐次近似先粗后精
  • 能诊断他人卡在哪一步并设计补偿动作
  • 说出策略的边界：知识不足时，策略救不了你

迁移（唯一真正的掌握标准）

  • 在真实工作问题中独立套用并产出可交付成果
  • 能出声示范给别人看（教就是最好的学）

三、五步操作定义表（核心资产：每一步都要有“产出物”）

步骤目的关键动作产出物（可检查证据）自检问句常见病症
怎么判断自己“真的做了”这一步 看产出物。没有产出物的步骤等于没做——这是本站所有练习的第一评价标准。

四、建模示范：专家出声思考

下面用一道公有领域的经典谜题，示范专家在心里到底说了什么。 请注意灰色的内心独白——策略的价值全在这些自问自答里。

题目：三人三兽渡河

三个人（P）与三只兽（B）在左岸，船最多载 2 个。任何一岸，只要有人在场，人数不得少于兽数， 否则兽会伤人。请把所有人与兽送到右岸。

第 1 步｜明确问题

「我先重述：起点（3P, 3B, 左），终点（0P, 0B, 右）。船容量 ≤ 2。 约束是人 ≥ 兽（人数不为 0 时）。我用（左岸人数, 左岸兽数, 船位）表示状态。 ⚠️ 我检查自己有没有偷偷加限制……我原本直觉“尽量往对岸送人”—— 但题目没说不能划回来。这可能就是关键。」

产出：已知 3P/3B/船容 2/约束；未知：摆渡序列；准则：全部过河且任一步不违反约束。

第 2 步｜探索思考（突破口所在）

「我想几条路：
① 直觉贪心：每次尽量送 2 个过去 → 很快发现船回不来（死路）
② 状态空间搜索：把所有合法状态画出来找路径 → 稳但慢
③ 目标导向倒推：从终点反推
④ 关键洞察：不只“向对岸送”，允许 1–2 个划回来——题目允许，但我一开始没用！
⑤ 类比：这像状态机转换，非法状态是陷阱。
我选 ②＋④。」

产出：4 条候选路径，选定“状态图 + 允许返回”。

第 3 步｜拟定计划

「以（左 P, 左 B, 船）为节点，从 (3,3,左) 走到 (0,0,右)， 每一步枚举所有合法移动，遇非法状态剪枝。 验证方式：走完后逐步回放，检查每一步左右两岸是否都满足 P ≥ B。」

产出：搜索 + 剪枝规则 + 回放验证。

第 4 步｜实施执行

#动作左岸右岸校核
1兽兽 →3人 1兽0人 2兽左 3≥1 ✓ 右无人 ✓
2兽 ←3人 2兽0人 1兽✓
3兽兽 →3人 0兽0人 3兽✓
4兽 ←3人 1兽0人 2兽✓
5人人 →1人 1兽2人 2兽左 1≥1 ✓ 右 2≥2 ✓
6人兽 ←（关键步）2人 2兽1人 1兽✓
7人人 →0人 2兽3人 1兽左无人 ✓ 右 3≥1 ✓
8兽 ←0人 3兽3人 0兽✓
9兽兽 →0人 1兽3人 2兽✓
10兽 ←0人 2兽3人 1兽✓
11兽兽 →0人 0兽3人 3兽完成 ✓

第 5 步｜回顾总结（高手分水岭）

  • 验证：回放 11 步，每步两岸均满足 P ≥ B（或人数为 0）→ 全部合法 ✓
  • 更简解：可证 11 步为最少步数，无更短解
  • 变体推广：4 人 4 兽、船容 2 → 无解；船容 3 → 步数改变；n 人 n 兽 → 可推广
  • 范例化（笛卡儿式收尾）：
    「凡是“带约束的状态转移问题”（排程、搬运、资源调度），都可以画状态图 + 剪枝 + 允许回退来解。」
  • 过程反思：我卡在第 6 步，因为“只往前送”的定势。下次遇到搬运／排程题，先问“我偷偷加了什么限制”。
范式的力量 笛卡儿说过：「我所解决的每一个问题，都将成为解其他问题的范例。」 回顾总结这一步，就是在制造“范例”。做一次，受益 N 次。

五、练习梯度：同构 → 近迁移 → 远迁移

A. 同构题（结构相同，换数字）

  1. 求和：1 + 2 + … + 59 = ? 用五步走，重点在探索步的“重新组合”。
  2. 渡河变体：4 人 4 兽，船容 3 → 有解吗？几步？

B. 近迁移题（换领域 / 换形式）

  1. 工程场景（本站自创）：某仓库拣货员平均每天走 12 公里，主管要求两周内把行走距离降 20%， 但不增加人手、不改造货架。用五步走，并说明你会在第几步决定“先做粗略估算”。（考“资源与准则”）
  2. 学习场景：选一门你一直学不会的技能，用五步拆解“为什么学不会”。

C. 远迁移题（真实工作与生活）

  1. 「我负责的项目总是延期」→ 用五步，产出一页 A4 改进提案。
  2. 「两份 Offer 怎么选」→ 用五步，写出你的准则与权重。
  3. 「和同事的一次合作卡住了」→ 用五步，写出问题陈述单与三条候选路径。
卡住时的三张提示卡（不给答案，只给钩子）
  • 卡住 → 回退到第 2 步
  • 只想到一条路 → 强制再想两条
  • 想放弃 → 问自己“我偷偷加了什么限制？”
打开五步执行单，现在就做一题 直接做掌握度自测

六、表现量规 Rubric

等级名称行为指标
L1未达跳过探索直接算；无回顾；答非所问
L2应知能背出五步名称与顺序；说得出每步的名字
L3应会陌生题按五步走完，每步有产出物，得正确解；探索 ≥3 条
L4迁移在非学科情境套用；能诊断他人卡点；能教他人；说得出策略边界

判定规则：L3 是及格线，L4 才是完全掌握。

七、形成性检查工具

7-1 错误归因表（把失败精确定位到某一步）

7-2 出门票（每单元结束前回答三题）

  1. （应知）写出五步策略的顺序。
  2. （应会）用五步解 17+18+…+23，只写“明确问题”与“探索思考”两步的产出。
  3. （元认知）我今天卡在第几步？下次我会怎么改？

7-3 自我解释单（对每一步追问“为什么”）

「我为什么这样做？」｜「这一步的根据是什么？」｜「如果换条件，这一步还成立吗？」

八、迁移题库（考理解，不考背诵）

Q1深度理解
四步版与六步版：后者为什么增加“增强动机”与“探索思考”？用你自己一次失败的解题经验举证。

评分点：① 说清两步的功能；② 用自己的经验证明“跳过探索导致选错路”；③ 说得出边界——动机过强反而有害。

Q2深度理解
“有了五步策略就能解决一切问题”——这句话错在哪？

评分点：策略是必要非充分；还需要知识背景、经验、态度与资源。

Q3深度理解
你用五步处理仓储拣货问题，得到粗略模型，误差 ±12%，而业务准则是 ±15%。该不该继续精化？

评分点：最佳解取决于资源与准则。已达准则即可交付并标注边界；要求提高精度再做逐次近似。

Q4迁移
用五步分析“部门的周会总是严重超时”，产出：问题陈述单 + 三条候选路径 + 一句范例化总结。

评分点：能否脱离学科语境，在真实组织中产出可交付的改进提案。
