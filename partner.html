找陪练

原著里「了解自己」的第一种方法，就叫寻找伙伴。 可现实里，很多人是一个人走的——身边没人愿意陪你做这种「慢思考」的事， 说了对方也未必懂。
这一页就是为了这些人。

为什么结对这件事不可替代 自己练，你听不出自己的盲区。因为盲区之所以叫盲区，就是你自己看不见。
倾听者的作用不是给你答案，是当一面镜子——他一开口给答案，镜子就碎了。

四种玩法

① 找搭子 —— 我一个人练不动

在下面的陪练墙留一行，等人和你组对。
留名最省事的办法是发一封邮件——下面有按钮，主题和格式都填好了； 想公开讨论的，也可以去 GitHub 发招募帖。

  1. 一人讲、一人听，角色必须互换
  2. 倾听者只说那七句话，绝不给答案
  3. 每周至少一次，每次 30 分钟
实在找不到人怎么办 用录音代替：自己讲一遍，隔一天再回听，标出卡点。 这比不讲强得多——但它不能完全替代，因为自己听不出自己的盲区。
去看陪练墙

② 当辅导员 —— 我可以带人

本站长期「招聘」辅导员。不是要求你多厉害， 是要求你忍得住不给答案。

报名前请先自查三条：

做过六维风格量表前测
完整填过 5 张以上五步执行单
承诺只说那七句话，绝不给答案
辅导员铁律 你一开口给答案，学员就停止思考了。
辅导员的价值不在懂得多，在忍得住。

同时——你有权拒绝任何一道题。一句 「这道题有标准答案，不适合约架，建议问老师」就够了。 这不叫不近人情，这叫不让这件事跑偏。
先背下倾听者七句话

③ 约架 —— 互相出题

A 出一道题给 B，B 做完填执行单，然后交换对照。

对照的价值在于看两个人卡在哪：

卡在同一步 → 说明那是多数人的坎

卡在不同步 → 你们能互相教

出题人的义务 收到应战三天内必须给反馈：你卡的那一步，我也卡过／我走的是另一条路。
不给反馈的约架，等于把人晾在半路。
看出题规则

④ 守擂 —— 一个人也能玩

公开一道题，谁都可以提交自己的五步执行单， 互相看别人怎么走。

这一条是给暂时找不到人的人留的： 就算没有对手，看看别人卡在哪一步，你也能照见自己。

为什么看别人的执行单有用 你会发现有人卡在第 2 步，有人卡在第 4 步， 而有人根本没意识到要检查单位—— 这些你自己在做的时候，全都看不见。

约架区：什么题可以约，什么题不要约

约架区不接受学科作业题。原因很简单： 一旦开放，这里会立刻变成免费作业辅导班，那我们就白做了。

出题前先过三问

问自己不合格的样子
这个题有唯一正确答案吗？有 → 不约
答案是数字、公式、术语吗？是 → 不约
换个行业的人会做吗？不会 → 不约

三问全过，才可以出。

能不能约，看这张表

✅ 可以约

  • 小区快递柜总爆仓，怎么改善？
  • 两个 offer 怎么选？
  • 想让家人改掉一个习惯，怎么开口？
  • 预算砍半，项目怎么办？
  • 怎么说服老板同意我的方案？

❌ 不要约

  • 这道题怎么解？
  • 这个公式怎么推？
  • 这段代码为什么报错？
  • 帮我看看作业对不对
  • 考试题、竞赛题、课后习题
一句话分清 可以约的题，没有标准答案，只有「在你的条件下更好的答案」；
不要约的题，是在找答案，不是在练能力。

陪练墙

愿意组对的人，名字会留在这里。用昵称就行， 别写真名、手机号、住址。

留名之前，请先读这三条 一、只留昵称与一个联系方式。真名、手机、住址、工作单位都不要写。
二、第一次交流只在公开场合。先用邮件或在 GitHub issue 里聊，别急着加私人微信。
三、任何让你付钱、投资、点陌生链接的「陪练」，一律当骗子。

怎么把名字放上来

本站没有后端，也不要求注册。有三条路，挑你最方便的：

最省事：发封邮件 点下面的按钮，会自动打开你的邮件软件，主题和格式都填好了，你只要补上自己的内容。 维护者收到后手工贴到墙上——网站依然不存任何数据。

不想用邮件？那就复制。 点「复制」把模板带走，粘到微信、QQ、任何地方都行。

第三条路：公开交流（可选） 想让其他人也看到、一起讨论，就去 GitHub Issue 发一条（需要 GitHub 账号， 不会用也没关系，走上面两条就行）：
找陪练 · 公开帖 辅导员 · 公开帖 约架 · 公开帖 执行单 · 公开帖

发过来的信息只用于贴墙，不外传、不做任何商业用途。 你也可以随时发邮件要求把自己的名字撤下来。

搭上以后：怎么陪，才真的有用

名字上了墙、加上了联系方式，接下来才是难的部分。陪练不是坐旁边看着，也不是替对方做。 下面三件事都出自原书，我们只是把它摆成了能用的样子。

陪练墙不是一套规范，是一个反馈回路 「每个解决问题者有不同需要！用反映作为指导！」 ——原书表 1-5「对倾听者的反映」末尾一句

一句是事实（各有不同需要），一句是方法（用反映做指导）。 所以这里不规定你该怎么陪练——做完一次，让对方填一填下面那张表，你据此调下一次。

一、先选角色：你想让对方怎么陪你

原书给了四个选项，由解题的人选，不是陪练的人选。 中间三种都不替你解题，但介入程度完全不同。

角色他做什么什么时候选它
沉默只在场，几乎不出声你想完全自己扛，只需要有个人在场
教练员提醒、鼓励、帮你把话说清楚卡住了，但不想被提示
引导者提问，把你往下一步引知道自己卡，但说不清卡在哪
中立者只复述、只确认，不给任何方向想检验自己说得通不通

还有一组可以勾选：希望对方强调哪些行为——倾听、帮表达、帮解决问题……按需勾，不必全给。

二、做完一次，用两条标尺调分寸

原书把陪练的分寸画成两条线。两端都不好：

标尺← 一端另一端 →
相互作用的方式太被动主动不断阻止
威胁感过多支援太有威胁

两条线画出的正是陪练的两种典型失败： 要么不管（太被动、支援过多变成哄），要么管太多（不断阻止、太有威胁变成审问）。

三、五条依据，都出自原书

依据原书怎么说
口语记录法
方法原型		 把思维活动大声说出来，由他人记录后分析。它的第 7 条帮助最要紧——促使我们把思考过程减慢下来：看懂是快的，快到你根本没看见自己是怎么想的。
倾听者的第一难
忍住不替做		 「他必须抵制试图自己解决该问题的诱惑而去辅导问题解答者。」——陪练最难的不是不会，是忍住不替对方做。
水平相当是误解
陪练不必是高手		 原书点名了这条误解：误认为只有和智力相同的人合伙才有收获。倾听者的职责是鼓励对方讲述、并讲得准确，不是替他解题。若陪练必须是高手，这套机制就做不成。
主持人禁用语五句
原话比我们编的权威		 「实际情况会怎么样」「解释一下你的意思」……只提问、不评判，主持人无权评判对错。
表 1-5 角色与分寸
本节上面两块		 态度不只属于解题的人，也属于陪练的人。原书第一章把两边都做了量表。

另有一处制度细节：原书两处独立规定小组 5~7 人、设负责人、且负责人无权判定主题或思想是否正确，可轮流担任。（第三章、第六章）

四、找线索四步：比「你再想想」管用

原书写「再认发生困难时便需要寻找线索」——那本身就是一套通用的提示技法， 不针对某一道题，任何卡壳都能用。

  1. 找事物各部分之间的联系
  2. 找各特点之间的联系
  3. 找它与环境的联系
  4. 找它与条件的联系

末句是原书原话：「依此线索寻找，或扩大线索的寻找。」 记住这四步，就不必再说「你再想想」——那句话不提供任何线索，只增加压力。 （第一章，记忆一节）

最后一句 这个站教的是「把解决问题变成可以验收的事」。
而找陪练，是把「一个人练」这件最容易半途而废的事，也变成可以看见的——
墙上有一个名字，你就不太好意思放弃了。
