贡献者

这个站不是一个人做出来的，更不是凭空长出来的——它本于一本 1992 年的书。 所以名单最前面的位置，永远留给那本书的编著者与出版者。此后凡是挑过错、出过题、写过章节、 提过被采纳建议的朋友，名字也都会留在这里。

0 位贡献者
0 项具体贡献

贡献者名单

原书的编著者与出版者恒定置顶——没有他们就没有这个站；其余按首次贡献时间排列。 用昵称也完全可以——重要的是你做过的事，不是你的真名。

贡献类型

贡献不分大小。指出一个错别字，和写一整章，在这里同样被记录。

怎么成为贡献者

  1. 做任何一件小事——挑个错、出道题、提个建议，都算。
  2. 告诉我们——到联系与共建页发邮件或开 Issue。
  3. 等它出现在这个页面上——维护者核实后会加进名单，并通知你。
想直接从代码层面参与？ 本站是开源的。会 Git 的朋友可以直接 Fork 仓库 → 改文件 → 提 Pull Request。 合并后你的名字会出现在 GitHub 的贡献者图表里，也会被加进这个页面。 具体改哪个文件，见联系与共建里的对照表。
一句话 这个站教的是「把解决问题变成可以验收的事」。 而贡献者名单，就是把「共建」这件模糊的好意，也变成可以看见的东西。
