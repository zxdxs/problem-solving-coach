贡献墙

这个站不是一个人做出来的，更不是凭空长出来的——它本于一本 1992 年的书。 所以名单最前面的位置，永远留给那本书的编著者与出版者。此后凡是挑过错、出过题、写过章节、 提过被采纳建议的朋友，名字也都会留在这里。

名单

原书的编著者与出版者恒定置顶——没有他们就没有这个站；其余按加入先后排列。 用昵称也完全可以——重要的是你做过的事，不是你的真名。

贡献类型

贡献不分大小。指出一个错别字，和写一整章，在这里同样被记录。

怎么成为贡献者

  1. 做任何一件小事——挑个错、出道题、提个建议，都算。
  2. 告诉我们——到联系页发邮件或开 Issue。
  3. 等它出现在这个页面上——维护者核实后会加进名单，并通知你。

参与方式（从低到高）

这个站点最需要的不是赞美，是这三件事。门槛从低到高：

① 挑错与建议

发现错别字、讲得不清楚、题目有歧义、某句话让你卡住了—— 直接开个 Issue 或写信。最低门槛，也是最有用的贡献。

② 补充题目

自己出一道好题（尤其是真实工作／生活场景题），连同答案和解析一起发过来。 站内的场景题都是这么来的。

③ 写章节 / 做翻译

把骨架章节扩成详填版，或翻译成其他语言。 可先读延伸阅读，了解这套方法的来龙去脉。

协作流程

  1. Fork 仓库到你自己名下
  2. 改你要改的文件（建议先从小处开始，比如加一道题）
  3. 提交 Pull Request，说明改了什么、为什么
  4. 合并后即发布——静态站没有复杂的构建步骤
共建前请先读这一段 贡献内容请自己写。例题优先选用经典问题，或用你自己的真实工作场景来设计。 更详细的说明见延伸阅读。
想直接从代码层面参与？ 本站是开源的。会 Git 的朋友可以直接 Fork 仓库 → 改文件 → 提 Pull Request。 合并后你的名字会出现在 GitHub 的贡献者图表里，也会被加进这个页面。 仓库地址见联系页；文件对照表就在本页上方。
